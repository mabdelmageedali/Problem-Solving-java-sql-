📂 Part 1 — Basic Selection & Filtering (Problems 1–5)
1
👀 Select All Employees
Retrieve all columns and rows from a table
📋 Problem

Retrieve all columns and rows from the employees table.

sqlSolution
SELECT * FROM employees;
🔑 Concept

The asterisk * is a wildcard meaning "select every column". Useful for exploration, but avoid in production code for performance.

2
🔍 Filter by Department
Use WHERE to filter specific rows
📋 Problem

Find the names and salaries of all employees who work in the IT department.

sqlSolution
SELECT name, salary FROM employees WHERE department = 'IT';
namesalary
Bob70000
Charlie80000
Grace90000
🔑 Concept

The WHERE clause filters records before they are returned. String comparisons are case-sensitive in some databases.

3
⬇️ Sort by Salary
Order results descending
📋 Problem

List all employees sorted by salary from highest to lowest.

sqlSolution
SELECT name, salary FROM employees ORDER BY salary DESC;
🔑 Concept

ORDER BY sorts the result set. DESC means descending (high to low). Default is ASC (low to high).

4
🧮 Count per Department
Group data and count occurrences
📋 Problem

How many employees work in each department?

sqlSolution
SELECT department, COUNT(*) AS employee_count FROM employees GROUP BY department;
departmentemployee_count
HR2
IT3
Sales3
🔑 Concept

GROUP BY collapses rows into groups. Aggregate functions like COUNT() then calculate values for each group.

5
🏆 Highest Earner
Find the maximum value
📋 Problem

What is the maximum salary in the company, and who earns it?

sqlSolution
SELECT name, salary FROM employees ORDER BY salary DESC LIMIT 1;
namesalary
Grace90000
🔑 Concept

Sorting by salary descending and taking the first row (LIMIT 1) is often faster than using subqueries for simple "top 1" questions.

📂 Part 2 — Comparison & Patterns (Problems 6–10)
6
💰 Salary Threshold
Filter using greater than operator
📋 Problem

Find all employees who earn more than 60,000.

sqlSolution
SELECT name, department, salary FROM employees WHERE salary > 60000;
🔑 Concept

Standard comparison operators (>, <, >=, <=) work on numbers and dates.

7
🌍 Unique Cities
Remove duplicate values
📋 Problem

List all distinct cities where employees are located.

sqlSolution
SELECT DISTINCT city FROM employees;
city
New York
Chicago
Boston
🔑 Concept

DISTINCT filters out duplicate rows in the result set, returning only unique combinations of the selected columns.

8
🔤 Name Pattern Matching
Use LIKE for wildcards
📋 Problem

Find all employees whose name starts with the letter "A".

sqlSolution
SELECT name, department FROM employees WHERE name LIKE 'A%';
namedepartment
AliceHR
🔑 Concept

% is a wildcard representing zero or more characters. 'A%' means "starts with A".

9
🤝 Join Employees & Departments
Combine two tables on a common column
📋 Problem

Show each employee's name along with their department's manager.

sqlSolution
SELECT e.name AS employee, d.dept_name, d.manager FROM employees e JOIN departments d ON e.department = d.dept_name;
🔑 Concept

JOIN (Inner Join) returns rows when there is a match in both tables based on the ON condition.

10
📈 High Average Departments
Filter groups using HAVING
📋 Problem

Find departments where the average salary is greater than 60,000.

sqlSolution
SELECT department, AVG(salary) AS avg_salary FROM employees GROUP BY department HAVING AVG(salary) > 60000;
departmentavg_salary
IT80000
Sales61000
🔑 Concept

WHERE filters rows before grouping. HAVING filters groups after aggregation.

📂 Part 3 — Advanced Filtering & NULLs (Problems 11–15)
11
❓ Handle NULL Commissions
Check for missing values
📋 Problem

Find all employees who do not receive a commission.

sqlSolution
SELECT name, department, commission FROM employees WHERE commission IS NULL;
⚠️ Important

Never use = NULL. It always returns false. Always use IS NULL or IS NOT NULL.

12
➕ Calculate Total Income
Handle NULLs in math with COALESCE
📋 Problem

Display name and total income (Salary + Commission). Treat NULL commission as 0.

sqlSolution
SELECT name, salary + COALESCE(commission, 0) AS total_income FROM employees;
🔑 Concept

COALESCE(val, 0) returns the value if it exists, or 0 if it is NULL. This prevents the whole sum from becoming NULL.

13
📅 Hire Date Range
Filter dates using BETWEEN
📋 Problem

Find employees hired between Jan 1, 2020 and Dec 31, 2020.

sqlSolution
SELECT name, hire_date FROM employees WHERE hire_date BETWEEN '2020-01-01' AND '2020-12-31';
🔑 Concept

BETWEEN is inclusive (includes the start and end dates). Equivalent to >= X AND <= Y.

14
🏷️ Column Aliases
Rename columns for readability
📋 Problem

Select name and salary, renaming them to "Employee Name" and "Yearly Salary".

sqlSolution
SELECT name AS "Employee Name", salary AS "Yearly Salary" FROM employees;
🔑 Concept

Use AS to create an alias. Quotes are required if the alias contains spaces.

15
🔝 Top 3 Earners
Limit the number of results
📋 Problem

List the top 3 highest-paid employees.

sqlSolution (MySQL/Postgres)
SELECT name, salary FROM employees ORDER BY salary DESC LIMIT 3;
ℹ️ SQL Server Variant

In SQL Server, use SELECT TOP 3 name, salary ... instead of LIMIT.

📂 Part 4 — Logic, Strings & Aggregates (Problems 16–20)
16
🎯 Multiple Conditions (IN)
Simplify OR logic
📋 Problem

Find employees in either HR or Sales.

sqlSolution
SELECT name, department FROM employees WHERE department IN ('HR', 'Sales');
🔑 Concept

IN is cleaner than writing dept = 'HR' OR dept = 'Sales'.

17
🔗 String Concatenation
Join text columns together
📋 Problem

Create a sentence: "Alice works in New York".

sqlSolution (MySQL/Postgres)
SELECT CONCAT(name, ' works in ', city) AS info FROM employees;
ℹ️ SQL Server Variant

Use the plus operator: SELECT name + ' works in ' + city ...

18
📊 Full Statistics
Multiple aggregates in one query
📋 Problem

Get the Min, Max, Avg, and Sum of all salaries.

sqlSolution
SELECT MIN(salary) AS lowest, MAX(salary) AS highest, AVG(salary) AS average, SUM(salary) AS total_payroll FROM employees;
🔑 Concept

You can run multiple aggregate functions in a single SELECT statement without GROUP BY to get stats for the whole table.

19
↩️ Left Join (All Depts)
Keep unmatched rows from the left table
📋 Problem

List all departments and their employees. Include departments even if they have no employees.

sqlSolution
SELECT d.dept_name, e.name FROM departments d LEFT JOIN employees e ON d.dept_name = e.department;
🔑 Concept

LEFT JOIN ensures every row from the left table (departments) appears, filling missing matches with NULL.

20
✏️ Update Salaries
Modify existing data safely
📋 Problem

Give a 10% raise to all IT employees.

sqlSolution
UPDATE employees SET salary = salary * 1.10 WHERE department = 'IT';
⚠️ Danger Zone

Always include a WHERE clause in UPDATE statements, or you will update every row in the table!

Min with Group By

Find the lowest salary in each department.

🔠 Order by Multiple Columns
Secondary sorting
📋 Problem

List employees sorted by Department (A-Z), then by Salary (High-Low) within that department.

sqlSolution

24
🔄 Case Statement
Create custom categories
📋 Problem

Label employees as "High Earner" if salary > 70k, otherwise "Standard".

sqlSolution
SELECT name, salary, CASE WHEN salary > 70000 THEN 'High Earner' ELSE 'Standard' END AS status FROM employees;
25
📅 Extract Year from Date
Date functions
📋 Problem

List names and the year they were hired.

sqlSolution (MySQL)
SELECT name, YEAR(hire_date) as hire_year FROM employees;
ℹ️ Variants

Postgres: EXTRACT(YEAR FROM hire_date). SQL Server: YEAR(hire_date).

26
🧮 Round Average Salary
Formatting numbers
📋 Problem

Calculate the average salary rounded to 2 decimal places.

sqlSolution
SELECT ROUND(AVG(salary), 2) as avg_sal FROM employees;
27
🗑️ Delete Specific Row
Remove data safely
📋 Problem

Delete the employee named "Henry".

sqlSolution
DELETE FROM employees WHERE name = 'Henry';
⚠️ Warning

Like UPDATE, always use WHERE with DELETE, or you will wipe the entire table.
