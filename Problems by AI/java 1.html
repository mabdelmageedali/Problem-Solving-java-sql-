🔢 Check if a Number is Even or Odd
Use the modulo operator to determine parity
📋 Problem Statement

Write a program that checks whether a given integer is even or odd.

💡 Key Concept

The modulo operator % returns the remainder of a division. If num % 2 == 0, the number is even; otherwise, it's odd.

java Solution
public class EvenOdd { public static void main(String[] args) { int num = 7; if (num % 2 == 0) { System.out.println(num + " is Even."); } else { System.out.println(num + " is Odd."); } } }
✅ Sample Output (num = 7)

7 is Odd.

✅ Sample Output (num = 10)

10 is Even.

🔑 Takeaway

The % operator is fundamental for checking divisibility in Java. It's used in many patterns including leap year checks and cycling through values.

🏆 Find the Largest of Three Numbers
Compare three integers using if-else chains
📋 Problem Statement

Given three numbers a, b, and c, find and print the largest one.

💡 Key Concept

Use an if-else if-else chain. Each branch checks whether a particular variable is greater than or equal to both of the others.

java Solution
public class LargestNumber { public static void main(String[] args) { int a = 15, b = 25, c = 10; if (a >= b && a >= c) { System.out.println(a + " is the largest."); } else if (b >= a && b >= c) { System.out.println(b + " is the largest."); } else { System.out.println(c + " is the largest."); } } }
✅ Sample Output

25 is the largest.

🔑 Takeaway

Chained if-else comparisons handle multi-way decisions. For more than three values, consider using Math.max() or an array-based approach.

🔁 Calculate the Factorial of a Number
Multiply all positive integers from 1 to N using a loop
📋 Problem Statement

Calculate the factorial of a given positive integer N. Recall that N! = N × (N−1) × … × 1.

⚙️ Algorithm
  • Initialize a variable factorial = 1
  • Loop from i = 1 to num, multiplying factorial *= i each time
  • After the loop, factorial holds the result
java Solution
public class Factorial { public static void main(String[] args) { int num = 5; long factorial = 1; for (int i = 1; i <= num; i++) { factorial *= i; // factorial = factorial * i } System.out.println("Factorial of " + num + " is: " + factorial); } }
✅ Sample Output

Factorial of 5 is: 120

⚠️ Common Mistake

Using int instead of long for the result. Factorials grow extremely fast — 13! already exceeds int range.

🔑 Takeaway

Factorial problems are a classic use of for loops and demonstrate how quickly values can grow, requiring larger data types.

🔄 Reverse a String
Build a reversed string by iterating from end to start
📋 Problem Statement

Write a method to reverse a given string without using built-in reverse functions.

💡 Key Concept

Use charAt(i) to access individual characters. Loop from the last index down to 0, appending each character to a new string.

java Solution
public class ReverseString { public static void main(String[] args) { String original = "Hello World"; String reversed = ""; for (int i = original.length() - 1; i >= 0; i--) { reversed += original.charAt(i); } System.out.println("Original: " + original); System.out.println("Reversed: " + reversed); } }
📥 Input

"Hello World"

✅ Output

"dlroW olleH"

🔑 Takeaway

String concatenation in a loop works for small inputs. For large strings, use StringBuilder for better performance.

🪞 Check if a String is a Palindrome
Compare characters from both ends moving inward
📋 Problem Statement

A palindrome reads the same forwards and backwards (e.g., "radar", "madam"). Check if a given string is a palindrome.

⚙️ Algorithm
  • Set two pointers: left = 0 and right = length - 1
  • Compare characters at left and right
  • If any pair mismatches, it's not a palindrome
  • Move inward until left >= right
java Solution
public class PalindromeCheck { public static void main(String[] args) { String str = "radar"; boolean isPalindrome = true; int left = 0; int right = str.length() - 1; while (left < right) { if (str.charAt(left) != str.charAt(right)) { isPalindrome = false; break; } left++; right--; } if (isPalindrome) { System.out.println(str + " is a palindrome."); } else { System.out.println(str + " is NOT a palindrome."); } } }
✅ Sample Output

radar is a palindrome.

🔑 Takeaway

The two-pointer technique is an efficient way to compare elements from both ends. It's used in many problems beyond palindromes.

📊 Find the Maximum Element in an Array
Scan through an array to find the highest value
📋 Problem Statement

Given an array of integers, find and print the highest value.

💡 Key Concept

Assume the first element is the maximum. Loop through the rest; whenever a larger element is found, update the maximum.

java Solution
public class MaxInArray { public static void main(String[] args) { int[] numbers = {12, 45, 67, 2, 89, 34}; int max = numbers[0]; for (int i = 1; i < numbers.length; i++) { if (numbers[i] > max) { max = numbers[i]; } } System.out.println("The maximum value is: " + max); } }
✅ Sample Output

The maximum value is: 89

🔑 Takeaway

This linear scan pattern runs in O(n) time and is the foundation for many array algorithms.

➕ Calculate the Sum and Average of Array Elements
Accumulate values using an enhanced for loop
📋 Problem Statement

Write a program to calculate the sum and average of all numbers in an array.

java Solution
public class ArraySumAverage { public static void main(String[] args) { int[] numbers = {10, 20, 30, 40, 50}; int sum = 0; for (int num : numbers) { sum += num; } double average = (double) sum / numbers.length; System.out.println("Sum: " + sum); System.out.println("Average: " + average); } }
✅ Output — Sum

Sum: 150

✅ Output — Average

Average: 30.0

⚠️ Common Mistake

Forgetting to cast to (double) before dividing. Integer division 150 / 5 gives 30, but 151 / 5 gives 30 instead of 30.2.

🔑 Takeaway

The enhanced for loop (for-each) provides cleaner syntax when you don't need the index. Always cast to double for precise averages.

🐇 Print Fibonacci Series up to N Terms
Generate the classic sequence where each term is the sum of the two before it
📋 Problem Statement

Print the first N numbers in the Fibonacci sequence: 0, 1, 1, 2, 3, 5, 8, …

💡 Key Concept

Each Fibonacci number is the sum of the two preceding ones. Maintain two variables first and second, then compute next = first + second in each iteration.

java Solution
public class Fibonacci { public static void main(String[] args) { int n = 7; int first = 0, second = 1; System.out.print("First " + n + " terms: "); for (int i = 1; i <= n; i++) { System.out.print(first + " "); // Compute next term int next = first + second; first = second; second = next; } } }
✅ Sample Output

First 7 terms: 0 1 1 2 3 5 8

🔑 Takeaway

The Fibonacci series teaches the concept of iterative state update — carrying forward previous results to compute the next one.

🔤 Count Vowels and Consonants in a String
Classify each character as a vowel, consonant, or non-letter
📋 Problem Statement

Given a string, count how many vowels (a, e, i, o, u) and consonants are present.

java Solution
public class CountVowels { public static void main(String[] args) { String str = "Java Programming"; str = str.toLowerCase(); int vowels = 0; int consonants = 0; for (int i = 0; i < str.length(); i++) { char ch = str.charAt(i); if (ch >= 'a' && ch <= 'z') { if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u') { vowels++; } else { consonants++; } } } System.out.println("Vowels: " + vowels); System.out.println("Consonants: " + consonants); } }
✅ Vowels

Vowels: 5 — a, a, o, a, i

✅ Consonants

Consonants: 10 — j, v, p, r, g, r, m, m, n, g

🔑 Takeaway

Convert to lowercase first to simplify comparisons. Always check that a character is actually a letter before classifying it.

🔀 Swap Two Numbers Without a Third Variable
Use arithmetic to exchange values in place
📋 Problem Statement

Swap the values of two integer variables without using a temporary third variable.

⚙️ How It Works

Given a = 5 and b = 10:

  • a = a + b → a becomes 15
  • b = a - b → b becomes 5 (original a)
  • a = a - b → a becomes 10 (original b)
java Solution
public class SwapNumbers { public static void main(String[] args) { int a = 5; int b = 10; System.out.println("Before swap: a = " + a + ", b = " + b); // Swapping without temp variable a = a + b; // a becomes 15 b = a - b; // b becomes 5 a = a - b; // a becomes 10 System.out.println("After swap: a = " + a + ", b = " + b); } }
✅ Sample Output

Before swap: a = 5, b = 10

After swap: a = 10, b = 5

🔑 Takeaway

This arithmetic trick avoids extra memory. An alternative is XOR swapping: a ^= b; b ^= a; a ^= b;. In practice, using a temp variable is clearer and preferred.

🔍 Check if a Number is Prime
Test divisibility up to the square root for efficiency
📋 Problem Statement

A prime number is greater than 1 and divisible only by 1 and itself. Check if a given number is prime.

💡 Key Concept

You only need to check divisors up to √num. If no divisor is found in that range, the number is prime. This reduces time complexity from O(n) to O(√n).

java Solution
public class PrimeCheck { public static void main(String[] args) { int num = 29; boolean isPrime = true; if (num <= 1) { isPrime = false; } else { for (int i = 2; i <= Math.sqrt(num); i++) { if (num % i == 0) { isPrime = false; break; } } } if (isPrime) { System.out.println(num + " is a Prime number."); } else { System.out.println(num + " is NOT a Prime number."); } } }
✅ Sample Output

29 is a Prime number.

🔑 Takeaway

The square-root optimization is crucial. For 29, instead of checking divisors 2–28, we only check 2–5. This matters greatly for large numbers.

📅 Check for a Leap Year
Apply the divisibility rules for leap year calculation
📋 Problem Statement

Determine whether a given year is a leap year.

💡 Leap Year Rules
  • Divisible by 4 → candidate for leap year
  • But if divisible by 100 → NOT a leap year
  • Unless ALSO divisible by 400 → IS a leap year
java Solution
public class LeapYear { public static void main(String[] args) { int year = 2024; boolean isLeap; if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) { isLeap = true; } else { isLeap = false; } if (isLeap) { System.out.println(year + " is a Leap Year."); } else { System.out.println(year + " is NOT a Leap Year."); } } }
✅ Sample Output

2024 is a Leap Year.

🔑 Takeaway

Compound boolean expressions with && and || can encode complex real-world rules in a single line.

🔢 Sum of Digits of an Integer
Extract digits one by one using modulo and division
📋 Problem Statement

Given an integer (e.g., 12345), calculate the sum of its individual digits: 1 + 2 + 3 + 4 + 5 = 15.

⚙️ Algorithm
  • lastDigit = temp % 10 — extracts the rightmost digit
  • temp /= 10 — removes the rightmost digit
  • Repeat until temp == 0
java Solution
public class SumOfDigits { public static void main(String[] args) { int number = 12345; int sum = 0; int temp = number; while (temp > 0) { int lastDigit = temp % 10; sum += lastDigit; temp /= 10; } System.out.println("The sum of digits of " + number + " is: " + sum); } }
✅ Sample Output

The sum of digits of 12345 is: 15

🔑 Takeaway

The % 10 and /= 10 pattern is a fundamental technique for digit-by-digit processing in Java.

↩️ Reverse an Integer
Build the reversed number digit by digit
📋 Problem Statement

Reverse the digits of an integer (e.g., 9876 becomes 6789).

💡 Key Concept

Extract the last digit with % 10, then build the reversed number by multiplying the current result by 10 and adding the digit.

java Solution
public class ReverseNumber { public static void main(String[] args) { int number = 9876; int reversed = 0; while (number != 0) { int digit = number % 10; reversed = reversed * 10 + digit; number /= 10; } System.out.println("Reversed number: " + reversed); } }
✅ Sample Output

Reversed number: 6789

🔑 Takeaway

This pattern is nearly identical to sum-of-digits, but instead of accumulating a sum, you build a new number positionally with reversed * 10 + digit.

🔎 Linear Search — Find an Element in an Array
Iterate through every element until the target is found
📋 Problem Statement

Search for a target value inside an array and print its index. If not found, print a message.

💡 Key Concept

Linear search checks each element one by one from left to right. It works on unsorted arrays and runs in O(n) time.

java Solution
public class LinearSearch { public static void main(String[] args) { int[] arr = {10, 25, 30, 45, 50}; int target = 45; int foundIndex = -1; for (int i = 0; i < arr.length; i++) { if (arr[i] == target) { foundIndex = i; break; } } if (foundIndex != -1) { System.out.println("Element " + target + " found at index: " + foundIndex); } else { System.out.println("Element not found in the array."); } } }
✅ Sample Output

Element 45 found at index: 3

🔑 Takeaway

Using -1 as a sentinel value for "not found" is a common Java convention. The break statement exits the loop early once the target is found.

⭐ Print a Right-Angled Star Pattern
Use nested loops to create a triangle of asterisks
📋 Problem Statement

Use nested loops to print a right-angled triangle pattern of asterisks with N rows.

💡 Key Concept

The outer loop controls rows. The inner loop controls how many stars are printed per row. Row i prints i stars.

java Solution
public class StarPattern { public static void main(String[] args) { int rows = 5; for (int i = 1; i <= rows; i++) { for (int j = 1; j <= i; j++) { System.out.print("* "); } System.out.println(); } } }
✅ Sample Output

*

* *

* * *

* * * *

* * * * *

🔑 Takeaway

Nested loops are essential for 2D patterns. The inner loop's boundary depending on the outer loop's variable is what creates the triangular shape.

🔠 Count Occurrences of a Character in a String
Scan through the string and tally matches
📋 Problem Statement

Count how many times a specific character appears inside a string.

java Solution

Character 'a' appears 3 times.

Character counting is a building block for frequency analysis, histograms, and anagram detection. The same pattern extends to counting words or substrings.

Build a new string by skipping space characters
📋 Problem Statement

Remove all space characters from a given string without using built-in replace methods.

🥈 Find the Second Largest Element in an Array
Track the top two values in a single pass through the array
📋 Problem Statement

Find the second highest number in an array of integers without sorting it.

⚙️ Algorithm
  • Initialize largest and secondLargest to Integer.MIN_VALUE
  • For each element: if it's greater than largest, shift largest down to secondLargest and update largest
  • Else if it's greater than secondLargest and not equal to largest, update secondLargest
java Solution
public class SecondLargest { public static void main(String[] args) { int[] arr = {12, 35, 1, 10, 34, 1}; int largest = Integer.MIN_VALUE; int secondLargest = Integer.MIN_VALUE; for (int num : arr) { if (num > largest) { secondLargest = largest; largest = num; } else if (num > secondLargest && num != largest) { secondLargest = num; } } if (secondLargest == Integer.MIN_VALUE) { System.out.println("There is no second largest element."); } else { System.out.println("Second largest element is: " + secondLargest); } } }
✅ Sample Output

Second largest element is: 34

⚠️ Edge Case

If all elements are identical (e.g., {5, 5, 5}), there is no distinct second largest. The condition num != largest handles this correctly.

🔑 Takeaway

Tracking multiple "best" values in a single pass is an O(n) technique. This extends to finding the k-th largest for small k values without needing to sort the entire array.
